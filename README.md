# Reto Técnico de Postventa Integral · Incomer

Evaluación interactiva (tipo juego) para técnicos nuevos de Postventa de Incomer, basada en la presentación y la evaluación de la Capacitación Postventa 2026.

- Pide nombre completo y cédula al inicio.
- 48 preguntas en 2 módulos: Visión y diagnóstico (24) y Visitas, seguimiento y servicio (24).
- Se aprueba cada módulo con **más del 85 %**; si no, la persona repite el módulo y no se genera el diploma.
- Al aprobar ambos módulos genera el diploma de **Técnico de Postventa Integral** (PNG y PDF) con el logo de Incomer.
- Accesible: lectura en voz alta (Web Speech API), atajos de teclado, tamaño de letra y alto contraste.

## Uso

Es un solo archivo estático (`index.html`), sin dependencias ni compilación; solo carga la fuente Poppins desde Google Fonts.
Abrir `index.html` en el navegador, o publicarlo con **GitHub Pages**: `Settings → Pages → Deploy from a branch → main / (root)`.

Esta versión no guarda resultados: todo ocurre en el navegador de cada persona.
